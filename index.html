-- Önce foreign key bağımlılığı olan tabloları ve ana tabloları güvenle silelim DROP TABLE IF EXISTS payments CASCADE; DROP TABLE IF EXISTS offers CASCADE; DROP TABLE IF EXISTS requests CASCADE; DROP TABLE IF EXISTS master_details CASCADE; DROP TABLE IF EXISTS profiles CASCADE; -- 1. KULLANICI / USTA PROFİLLERİ TABLOSU CREATE TABLE profiles ( id UUID REFERENCES auth.users NOT NULL PRIMARY KEY, full_name TEXT NOT NULL, phone TEXT UNIQUE NOT NULL, user_type TEXT CHECK (user_type IN ('client', 'master', 'admin')) DEFAULT 'client', created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW() ); -- 2. USTA DETAYLARI VE DOĞRULAMA TABLOSU CREATE TABLE master_details ( id UUID PRIMARY KEY DEFAULT gen_random_uuid(), user_id UUID REFERENCES profiles(id) ON DELETE CASCADE UNIQUE NOT NULL, category TEXT NOT NULL, national_id TEXT, -- T.C. Kimlik No document_url TEXT, -- Ustalık belgesi / Vergi levhası selfie_url TEXT, -- Selfie görseli is_verified BOOLEAN DEFAULT FALSE, -- Doğrulanmış Usta Rozeti is_vip BOOLEAN DEFAULT FALSE, -- VIP Üye vip_expires_at TIMESTAMP WITH TIME ZONE, rating DECIMAL(2,1) DEFAULT 0.0, created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW() ); -- 3. KULLANICI TALEPLERİ TABLOSU (9.99 TL) CREATE TABLE requests ( id UUID PRIMARY KEY DEFAULT gen_random_uuid(), client_id UUID REFERENCES profiles(id) ON DELETE CASCADE NOT NULL, title TEXT NOT NULL, description TEXT NOT NULL, category TEXT NOT NULL, city TEXT NOT NULL, district TEXT NOT NULL, status TEXT CHECK (status IN ('pending_payment', 'active', 'completed', 'cancelled')) DEFAULT 'pending_payment', is_paid BOOLEAN DEFAULT FALSE, payment_id TEXT, created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW() ); -- 4. USTA TEKLİFLERİ TABLOSU (24.99 TL veya VIP Ücretsiz) CREATE TABLE offers ( id UUID PRIMARY KEY DEFAULT gen_random_uuid(), request_id UUID REFERENCES requests(id) ON DELETE CASCADE NOT NULL, master_id UUID REFERENCES profiles(id) ON DELETE CASCADE NOT NULL, price_offer DECIMAL(10,2) NOT NULL, message TEXT, is_paid BOOLEAN DEFAULT FALSE, status TEXT CHECK (status IN ('pending', 'accepted', 'rejected')) DEFAULT 'pending', created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(), UNIQUE (request_id, master_id) ); -- 5. ÖDEME KAYITLARI TABLOSU CREATE TABLE payments ( id UUID PRIMARY KEY DEFAULT gen_random_uuid(), user_id UUID REFERENCES profiles(id) ON DELETE CASCADE NOT NULL, amount DECIMAL(10,2) NOT NULL, payment_type TEXT CHECK (payment_type IN ('client_request', 'master_offer', 'master_vip')), reference_id UUID, status TEXT CHECK (status IN ('success', 'failed', 'refunded')) DEFAULT 'success', created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW() );
